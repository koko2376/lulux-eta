LULUX ETA ships some built-in skills (in `packages/server/skills/`, installed to `<resources>/skills`) that were imported, with modifications, from the official **NousResearch/hermes-agent** repository (https://github.com/NousResearch/hermes-agent), commit `1f91fb386a60f5589146b05ee88e911bb58120e8`, licensed under the **MIT License**. Modifications: tool names adapted to LULUX tools (`workspace_read`, `workspace_write`, `fetch_url`, `run_skill_script`, `search_emails`, `create_email_draft`, `skill_view`), references to Hermes-only infrastructure (cron jobs, connector skills, `~/.hermes` paths) removed or replaced, frontmatter rewritten (source, upstream commit, license, original author kept). Each imported `SKILL.md` records `source`, `upstream-commit`, `license: MIT` and the original `author`. Machine-readable list: `packages/server/skills/THIRD_PARTY_SKILLS.json`.

All other built-in skills are original LULUX ETA work. No skill text or code was taken from Ekko Studio / ekko-agent or from Anthropic's document skills. Hermes skills whose directory carries its own LICENSE/NOTICE file or that state a non-MIT origin (e.g. Anthropic) were **not** imported.
