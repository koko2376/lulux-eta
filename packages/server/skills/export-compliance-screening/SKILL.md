# 出口合规与制裁筛查（提示性）

> **重要声明**：本技能只提供初步筛查思路与记录模板，**不构成法律意见**。名单经常更新、同名/音译差异大，任何疑似命中或高风险情形都必须由企业合规负责人、专业律师或货代/银行合规部门人工复核后再决定是否交易。

## 一、筛查对象
买方公司、收货人、最终用户、通知人、付款方（尤其第三方付款）、关联个人（股东/董事）、目的国与转运国、产品与用途。

## 二、名单与查询入口（用 `fetch_url` / `web_search` 查询，记录查询时间与结果截图/文本）
| 名单 | 入口 |
| --- | --- |
| 联合国安理会综合制裁名单 | scsanctions.un.org / un.org/securitycouncil/content/un-sc-consolidated-list |
| 美国 OFAC SDN 及其他名单 | sanctionssearch.ofac.treas.gov |
| 美国综合筛查名单 CSL（含 BIS Entity List、Denied Persons、Unverified List、Military End User 等） | trade.gov/consolidated-screening-list（提供搜索与下载） |
| 欧盟金融制裁综合名单 | data.europa.eu “Consolidated list of persons, groups and entities subject to EU financial sanctions”；EU Sanctions Map（sanctionsmap.eu） |
| 英国 OFSI 综合名单 | gov.uk “UK sanctions list” |
| 中国出口管制管控名单、不可靠实体清单、反制裁清单 | 商务部（mofcom.gov.cn）公告 |
| 其他 | 日本、加拿大、澳大利亚、瑞士等国家名单（视目的地与结算币种） |

搜索技巧：用公司英文名、本地语言名、简称、地址、关键人物分别查；注意音译（如 Mohammad/Muhammad）、公司后缀（LLC/OOO/FZE）；查到相似名称时比对国家、地址、注册号。

## 三、目的地与产品
- **全面/重点制裁国家与地区**：交易前必须专门评估（如朝鲜、伊朗、叙利亚、古巴，以及俄罗斯/白俄罗斯相关行业制裁、克里米亚等地区）；涉及美元结算或美国原产成分时，美国制裁可能适用。
- **两用物项**：对照《中华人民共和国两用物项出口管制条例》及管制清单、欧盟 2021/821 附件、美国 CCL（ECCN）。常见敏感：高性能芯片与电子、加密设备、无人机及零件、精密机床、特定化学品、传感器与激光、导航设备等。需要许可证的必须先申请。
- 军事/警用最终用途：一般禁止或须许可。

## 四、红旗信号（出现任一项需升级复核）
- 客户不愿说明最终用户或用途；用途与客户业务不符。
- 要求发往与客户所在国不同的第三国，或频繁更换收货人/转运港。
- 付款来自无关第三方或高风险国家；要求用现金/加密货币。
- 愿意支付明显高于市场的价格、不关心技术参数与售后。
- 要求在单据上模糊品名、低报价值、删除原产地或改唛头。
- 公司信息查不到、成立不久、地址是虚拟办公室或住宅。

## 五、筛查记录模板（`workspace_write` 存为 `合规筛查-<客户>-<日期>.md`）
```
筛查日期：YYYY-MM-DD｜筛查人：…（AI 初筛，需人工复核）
对象：公司 / 个人 / 地址 / 国家
| 名单 | 查询词 | 结果（未命中/疑似命中/命中） | 证据 |
产品：… HS … 是否疑似两用物项：是/否/不确定（依据）
目的地风险：低/中/高（依据）
红旗信号：无 / …
初步结论：可继续（常规）/ 需人工复核 / 建议暂停
待复核事项：…
```

## 注意
- 不要因为“未命中”就认定安全：名单只是一部分，行业制裁与所有权规则（如持股 ≥ 50% 的被制裁方控制的实体）也会适用。
- 不要帮助规避制裁或管制（例如建议改单、转口隐瞒最终用户），遇到此类请求应明确拒绝并提示风险。
