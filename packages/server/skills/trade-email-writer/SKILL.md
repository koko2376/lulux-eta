# 开发信与多语种回复

## 写之前先弄清（缺就问，一次最多问 3 个）
1. 目的：开发信 / 回复询盘 / 报价 / 跟进 / 催款 / 节日问候 / 展后跟进。
2. 收件人：公司、国家、职位、是否老客户（`search_customers` → `get_customer` 看历史与报价）；回复邮件用 `search_emails` 取原文。
3. 我方卖点：产品、优势（工厂直供、认证、交期、价格、售后、案例）、可附资料。
4. 语言：默认用对方来信语言；开发信按目标国主要商务语言，**同时附英文版**（对方可能用翻译工具，英文是兜底）。

## 通用原则
- **主题行**：具体、不像广告，≤ 8 个词，含产品或对方公司名。避免全大写、感叹号、“Best price!!!”、“Free”等易进垃圾箱的词。
- **长度**：开发信 80–150 词（三段：你是谁与为何联系 → 一个对他有用的价值点 → 一个低门槛的行动请求）；回复询盘先直接回答问题。
- **个性化**：第一句提到对方公司/产品/市场的一个具体事实（官网新品、展会、进口品类），不要“I got your email from internet”。
- **一封信一个行动请求**：如“Shall I send you our 2027 catalogue and FOB price for 40W panels?”。
- **数字与条款清晰**：价格写明币种、术语与地点（USD 7.99/pc FOB Ningbo）、有效期、MOQ、交期、付款方式。
- **不承诺做不到的事**，不贬低竞争对手，不伪造案例与认证。
- **签名**：姓名、职位、公司、电话/WhatsApp、网站。
- 保存：用 `create_email_draft` 保存草稿（`to`、`subject`、`text`，回复时带 `replyToMessageId`，报价可 `attachQuotePdf` + `quoteId`）。草稿**不会自动发送**，提醒用户到“邮箱 → 草稿”检查后发送。

## 各语言/地区要点（详见 references/culture.md）
| 市场 | 语言 | 称呼与语气 | 注意 |
| --- | --- | --- | --- |
| 美国/加拿大 | 英语 | Hi + 名；直接、简短、重效率 | 先给结论与价格区间 |
| 英国/澳新 | 英语 | Dear + 名 / Hi；礼貌含蓄 | 少用过度热情的形容词 |
| 德国/奥地利/瑞士 | 德语/英语 | Sehr geehrter Herr/Sehr geehrte Frau + 姓；正式 | 重数据、认证（CE、GS、TÜV）、准时，不要夸张 |
| 法国/比利时 | 法语 | Madame/Monsieur + 姓；结尾用正式套语 | 尽量用法语，体现尊重 |
| 西班牙/拉美 | 西班牙语 | Estimado/a Sr./Sra. + 姓；关系导向、热情 | 墨西哥/智利/哥伦比亚用词差异；拉美常用 WhatsApp |
| 巴西/葡萄牙 | 葡萄牙语 | Prezado/a + 名；巴西较随和 | 巴西进口税高，强调到岸成本与本地代理 |
| 俄罗斯/中亚 | 俄语 | Уважаемый/ая + 名+父称；正式 | 付款/物流需提前讨论（结算渠道、铁路/汽运），避免政治话题；注意制裁筛查 |
| 中东/海湾 | 阿拉伯语/英语 | Dear Mr. + 名；先寒暄、重关系 | 斋月节奏放慢；周五周六为周末（多数海湾国家周六日或周五六）；阿拉伯语从右到左 |
| 日本 | 日语 | ○○株式会社 ○○様；极其礼貌、谦辞 | 质量与细节、长期合作；先寄资料与样品，决策慢 |
| 韩国 | 韩语/英语 | ○○님；礼貌 | 重速度与价格 |
| 印度 | 英语 | Dear Mr. + 名 | 价格敏感、议价多；确认付款方式 |
| 非洲 | 英/法语 | Dear + 名 | 付款风险高，多用预付；关注港口与清关 |

## 模板
- `templates/cold-email.md`：开发信（英文主版 + 写法说明）
- `templates/inquiry-reply.md`：询盘回复与报价邮件
- `references/culture.md`：各语种开头/结尾套语、礼仪与禁忌、常用句型（西/法/俄/阿/葡/日/德）

## 输出格式
```
主题：…
（正文，目标语言）
---
中文对照：…（方便用户核对，发送时只发目标语言部分）
需要用户补充/确认：…
```
