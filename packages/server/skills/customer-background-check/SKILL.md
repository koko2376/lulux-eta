# 客户背景调查

> 只使用公开、合法的信息来源；不要尝试登录需要账号的网站、绕过付费墙或收集个人隐私（家庭住址、私人社媒等）。
> 结论标注“已核实 / 未核实 / 推测”，背调报告不是信用担保。

## 需要的输入
公司名（最好有英文全称）、国家、网站或邮箱域名、联系人姓名与职位。缺什么先问用户，或从询盘邮件/客户档案（`search_customers` → `get_customer`）里取。

## 调查步骤（按性价比排序，每步记录来源 URL）
1. **官网**（`fetch_url` 首页、About、Products、Contact）
   - 业务是否与询盘产品相关；公司历史、规模、门店/仓库/工厂照片；地址与电话是否与签名一致。
   - 页面是否像模板站、内容是否空洞；版权年份是否陈旧。
2. **域名与邮箱**
   - `web_search` 查 “域名 whois” 或用 `fetch_url` 访问 `https://rdap.org/domain/<域名>` 看注册时间（新注册 < 6 个月 + 大额订单 = 高风险）。
   - 邮箱域名与官网域名是否一致；免费邮箱需要更多佐证。
3. **公司注册信息**（按国家选官方/公开渠道，`web_search` “<公司名> company registration”）
   - 英国 Companies House、美国各州 Secretary of State、德国 Handelsregister/Northdata、法国 Pappers/Societe.com、印度 MCA、阿联酋各自贸区注册处、巴西 CNPJ 查询等。
   - 核对：注册号、成立时间、状态（Active/Dissolved）、注册地址、董事/股东是否与联系人一致。
4. **海关/提单数据思路**（判断是否真实进口商与采购量级）
   - 公开渠道：ImportYeti（美国海运提单，免费可查）、Panjiva/ImportGenius/Volza/52wmb 等（多为付费，仅提示用户可自行查询）。
   - 关注：近 12 个月进口次数、主要 HS 编码与品名、主要中国供应商（竞争对手）、出运港与频率、货量级别。
   - 搜索技巧：`web_search` “<公司名> importyeti” 或 “<公司名> bill of lading”。
5. **社媒与人员**
   - LinkedIn 公司页：员工数、行业、发帖活跃度；联系人职位是否为采购/老板。只看公开资料。
   - Facebook/Instagram 店铺（零售/电商类客户）、YouTube 产品视频、Google Maps 门店照片与评价。
6. **新闻与口碑**：`web_search` “<公司名> fraud / scam / lawsuit / bankrupt”，以及当地语言关键词；B2B 平台（Alibaba、Made-in-China）买家信息仅作参考。
7. **合规筛查**：按 `export-compliance-screening` 技能对公司名、联系人、目的国做制裁/实体清单检查。

## 风险评级
- **低**：官网与业务吻合、注册信息可查且存续 > 3 年、有进口记录或线下门店。
- **中**：部分信息无法核实（如小公司无海关记录），但无负面信号 → 正常报价，付款用 T/T 预付比例 ≥ 30% 或 L/C。
- **高**：域名新注册、注册信息查不到/已注销、冒用他人公司、负面新闻、命中制裁 → 只接受 100% 预付或不交易，提醒用户谨慎。

```
# 客户背调：<公司英文名>（<国家>）  日期：YYYY-MM-DD
**结论**：风险 低/中/高｜采购能力 大/中/小/未知｜建议：…

| 项目 | 结果 | 状态 | 来源 |
| --- | --- | --- | --- |
| 官网 | … | 已核实/未核实 | URL |
| 域名注册 | 2012-05-03 注册 | 已核实 | rdap.org |
| 公司注册 | 编号/状态/成立时间 | … | … |
| 进口记录 | 近 12 月 x 票，主要 HS … | 推测 | … |
| 联系人 | 姓名/职位 | … | LinkedIn |
| 负面信息 | 未发现 / … | … | … |
| 制裁筛查 | 未命中（需人工复核） | … | … |

## 业务判断
- 客户类型：进口商/批发商/品牌商/零售商/电商/贸易中间商/项目商
- 可能的采购量与价位：…
- 主要竞争供应商：…
## 建议的商务策略
- 报价策略、付款方式、是否寄样（免费/收费）…
## 待核实事项
- …
```
